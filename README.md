# Gestion_negocio-updates

Repositorio público auxiliar de **GestorPro**. Su único propósito es publicar
`version.json` y el instalador (`GestorPro-Setup.exe`) para que el chequeo de
actualizaciones dentro de la app pueda leerlos sin autenticación.

El código fuente de GestorPro vive en un repositorio **privado** aparte y no
se publica aquí.
